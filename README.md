# Modern JavaScript Learning Course

Welcome to your Modern JavaScript course. This repository is structured to help you learn current JavaScript features, best practices, and real-world usage.

## Course Structure

- `lessons/` — guided lesson notes and examples.
- `exercises/` — hands-on problems to practice each topic.
- `starter/` — a sample modern JavaScript starter app.
- `capstone/` — full sample todo app for the final project.

## How to use this course

1. Start with `lessons/01-intro-modern-javascript.md`.
2. Read one lesson at a time, and try the examples.
3. Complete the matching exercise in `exercises/`.
4. Revisit lessons and apply concepts in your own small projects.

## Recommended workflow

- Read a lesson fully.
- Copy code examples into a local editor or browser console.
- Complete the corresponding exercise immediately after.
- Check your understanding by explaining the concept in your own words.

## Topics covered

1. Modern JavaScript overview
2. `const`, `let`, destructuring, and template literals
3. Functions: arrow, default, rest/spread
4. Objects, classes, and modules
5. Promises, async/await, and `fetch`
6. DOM manipulation and events
7. Tooling and testing basics
8. Arrays, Sets, Maps, and iteration
9. Browser APIs, timers, and error handling
10. ESNext features and modern patterns
11. Capstone project: build a small app
