# Lesson 1: Introduction to Modern JavaScript

## What is modern JavaScript?

Modern JavaScript refers to the language features introduced since ES6 (2015) and the programming style used in current web development.

Key ideas:
- Use `const` and `let` instead of `var`
- Prefer arrow functions and concise syntax
- Work with modules and reusable components
- Handle asynchronous tasks with Promises and `async`/`await`
- Manipulate the DOM using modern APIs

## Why it matters

Modern JavaScript is more readable, safer, and easier to maintain.
It is used in web apps, mobile apps, servers, and desktop applications.

## Quick modern syntax examples

### `const` and `let`
```js
const name = 'Alex';
let age = 28;
age += 1;
```

### Template literals
```js
const message = `Hello, ${name}! You are ${age} years old.`;
console.log(message);
```

### Arrow functions
```js
const add = (a, b) => a + b;
console.log(add(2, 3));
```
